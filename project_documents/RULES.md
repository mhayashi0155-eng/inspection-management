# 開発・運用ルール

本プロジェクトにおける開発および運用に関する絶対遵守ルールです。
AIアシスタントおよび開発者は、本ファイルの内容を常に確認し、順守してください。

## 1. 言語・品質

- **日本語の徹底**: 全ての回答、成果物（計画書、手順書等）、コード内のコメントは**日本語**で記述すること。
- **丁寧な表現**: 簡潔かつ丁寧な日本語を使用すること。

## 2. バージョン管理

ファイルを修正する際は、必ず以下の **3箇所** のバージョン情報を最新（日付・内容）に更新すること。

1. **HTMLコメント**: `<!-- Version: vYYYY.MM.DD-VerXX_Name -->`
2. **リソース読み込み**: CSS/JSタグの `?v=...` パラメータ
3. **画面表示**: フッターや特定要素（`#version-indicator`）のテキスト

## 3. サイト更新（デプロイ）

作業完了時（タスク完了時）は、**AIアシスタントが代行して**必ず以下のGitコマンドを実行し、リポジトリへ変更を反映すること。
（ユーザーへのコマンド提示ではなく、AIが実行すること）

```bash
git add .
git commit -m "変更内容の要約"
git push origin main
```
